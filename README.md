About Project

Flexbox Playground allows users to create, manage, and customize flex items in real time. The application provides an interactive interface for changing Flexbox properties and immediately seeing how they affect the layout.

Features Add new flex items Remove existing items Change display Configure flex-direction Adjust justify-content Adjust align-items Modify flex-grow Modify flex-shrink Modify flex-basis Real-time layout preview Technologies React JavaScript Vite CSS React Hooks Installation npm install

Run the project:

npm run dev Project Structure src/ ├── components/ ├── App.jsx ├── main.jsx └──
